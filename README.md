# Rapp

Funcionalidades:
- `calc_stats(vals)`: media, mediana y sd de un vector de 10 valores.
- `plot_vals(vals)`: gráfico tipo “línea+puntos” de esos 10 valores.
- `run_gui()`: mini-app tcltk para ingresar los valores y ejecutar botones.
